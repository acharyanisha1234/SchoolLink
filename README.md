# SchoolLink

SchoolLink is a web-based School Management System designed to simplify and digitalize daily school operations. It provides a centralized platform for managing students, teachers, classes, attendance, examinations, fees, and other administrative activities. The system aims to improve efficiency, reduce manual paperwork, and provide an easy-to-use interface for school administrators, teachers, and students.

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- React Icons
- Sonner

### Backend
- Node.js
- Express.js

### Database
- MongoDB
